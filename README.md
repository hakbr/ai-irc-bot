# ai-irc-bot
And IRC bot powered by artificial intelligence
IRC BotThis is a Python-based IRC bot that connects to an IRC server, joins a channel, and responds to messages using a language model from Hugging Face.FeaturesIRC Connectivity: Connects to a specified IRC server and channel.Message Handling: Listens for messages in the channel.AI-Powered Responses: When the bot is triggered by a specific word, it generates a response using a Hugging Face language model.Error Handling: Handles socket errors, connection issues, and Hugging Face API errors.Logging: Logs all sent and received messages to a file.Reconnection: Automatically reconnects to the IRC server if disconnected.RequirementsPython 3.xirc.py library:pip install irc
requests library:pip install requests
A Hugging Face API key.An IRC server and channel.SetupInstall Dependencies:pip install irc requests
Configuration:Set the following variables in the mybot.py script:SERVER: The IRC server address (e.g., "irc.oftc.net").PORT: The IRC server port (e.g., 6667 for standard IRC, 6697 for SSL).CHANNEL: The IRC channel to join (e.g., "#my_channel").NICK: The bot's nickname.PASSWORD: The server password, if required (optional).HUGGINGFACE_API_KEY: Your Hugging Face API key.HUGGINGFACE_MODEL: The Hugging Face model to use (e.g., "google/flan-t5-base").AI_PREFIX: Text to add before the AI's response.TRIGGER_WORD: The word that triggers the bot to respond (e.g., "mybot").MAX_RESPONSE_LENGTH: The maximum length of the bot's response.LOG_FILE: The name of the file to log chat messages.Run the Bot:python mybot.py
UsageOnce the bot is running, it will connect to the specified IRC server and join the channel.  When a user in the channel sends a message that starts with the TRIGGER_WORD (e.g., "mybot"), the bot will:Extract the rest of the message as a prompt.Send the prompt to the Hugging Face API to generate a response.Send the response back to the IRC channel.Log the interaction to the chat_log.txt file.Code Overviewconnect_to_irc(): Connects to the IRC server, handles nickname registration, and joins the channel.  It also handles reconnection logic.send_message(channel, message): Sends a message to the specified channel and logs it.get_huggingface_response(prompt, model_name, api_key): Sends a request to the Hugging Face API to generate a response based on the given prompt.log_message(sender_nick, message): Logs a message to the chat_log.txt file.handle_irc_message(message): Parses incoming IRC messages, responds to PING requests, and processes messages containing the trigger word to generate AI responses.receive_messages(): Receives messages from the IRC server and passes them to handle_irc_message().  It also handles disconnections and reconnection.main():  Connects to the IRC server, starts the message receiving thread, and keeps the bot running.Error HandlingThe bot includes error handling for the following:Socket errors during connection and sending/receiving messages.Nickname already in use.Hugging Face API request errors.Unexpected errors during message processing.Disconnection from the server.ReconnectionThe bot will automatically attempt to reconnect to the IRC server if the connection is lost.LoggingAll sent and received messages are logged to the chat_log.txt file.  Each message is logged with a timestamp and the sender's nickname.To DoAdd more sophisticated command parsing.Implement more IRC event handling.Improve error handling and logging.Add support for SSL connections.Implement a mechanism to prevent the bot from flooding the channel.
